# 쪼개 상황실(a) · macOS

아홀로 루파 채널 전용 macOS 앱입니다. 루파의 치지직·YouTube 채널과 연결된 네이버 카페를 대상으로 동작합니다. 다른 스트리머나 채널 선택은 지원하지 않습니다.

- 치지직·YouTube 채널 정보 확인과 바로가기
- 네이버 카페 공지 확인
- 사용 치즈 기록 달력과 그래프
- 방송 기록 달력과 썸네일 보관
- macOS 위젯과 알림
- 창 크기에 맞춘 화면 배치

## 배포 및 설치

배포 파일과 설치 안내는 [릴리즈](https://github.com/xXkurotoriXx/jjogae-macOS/releases)에 등록합니다.

macOS 26 이상 · Apple Silicon 및 Intel.

DMG를 열고 앱을 응용 프로그램 폴더로 옮깁니다. 처음 실행할 때 Apple의 확인 안내로 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기 → 열기를 선택합니다.

현재 Apple Development 서명이며 Developer ID 서명과 Apple 공증은 완료하지 않았습니다. 다른 Mac의 실제 설치·로그인·위젯은 검증하지 않았습니다.
