# 쪼개 상황실 · macOS

아홀로 루파의 치지직·YouTube 채널과 네이버 카페 정보를 모아 보는 macOS 팬 앱입니다.

## 주요 기능

- 홈: 방송 상태, 팔로워·구독자 수, 팔로우·구독·멤버십 기간, 데뷔일·생일 확인
- 사용 치즈: 월간 달력, 날짜별 사용 내역, 최근 14일 그래프, 월 기준 일평균
- 카페: 공지 확인, 기간을 지정한 과거 공지 불러오기와 복구
- 방송 기록: 월간 달력, 방송 시간 통계, 다시보기 목록, 썸네일 보관·가져오기·내보내기
- 위젯: 채널 지표와 이용 기간 표시, 클릭하여 앱 창 열기
- macOS 알림: 방송 시작·종료·제목 변경, 새 영상·공지, 기념일과 결제일 안내
- 설정: 새로고침 간격, 배경 이미지 선택, 창 투명도, 기록 가져오기·내보내기
- 창 크기에 맞춰 바뀌는 화면 배치와 탐색 메뉴
- 바로가기: 치지직, YouTube 아홀로 루파, YouTube 아홀로그, 네이버 카페

## 설치

macOS 26 이상 · Apple Silicon 및 Intel

1. [최신 릴리즈](https://github.com/xXkurotoriXx/jjogae-macOS/releases/latest)에서 DMG를 받습니다.
2. DMG를 열고 **쪼개 상황실.app**을 **응용 프로그램**으로 옮깁니다.
3. 실행이 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기 → 열기**를 선택합니다.
4. 앱 설정에서 치지직·네이버와 YouTube에 로그인합니다.

## 업데이트

설정 또는 앱 메뉴의 **업데이트 확인**을 누르고 **업데이트 설치 → 설치 및 재실행**을 선택합니다. 앱은 GitHub의 공개 배포 파일을 내려받고 서명을 확인한 뒤 교체합니다. 기록과 설정은 유지됩니다.

**업데이트 자동 확인**을 켜면 앱이 실행되는 동안 주 1회 새 버전을 확인합니다. 설치는 업데이트 안내에서 선택합니다.
