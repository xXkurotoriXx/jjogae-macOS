# 쪼개 상황실 · macOS

**아홀로 루파 채널 전용 macOS 팬 앱**

치지직 방송과 YouTube 영상, 카페 공지부터 치즈 후원 내역과 구독 기간까지 한곳에서 확인할 수 있습니다. 방송 기록은 달력으로 살펴보고, 채널 정보는 macOS 위젯과 알림으로 확인할 수 있습니다.

[최신 버전 다운로드](https://github.com/xXkurotoriXx/jjogae-macOS/releases/latest) · [개인정보처리방침](./PRIVACY.md) · [문의 및 오류 제보](https://github.com/xXkurotoriXx/jjogae-macOS/issues)

## 주요 기능

### 상황실

방송 상태와 최신 영상, 팔로워·구독자 수를 한 화면에서 확인합니다. 팔로우·구독·멤버십 기간과 데뷔일·생일도 함께 표시합니다.

치지직, **YouTube 아홀로 루파**, **YouTube 아홀로그**, 네이버 카페로 바로 이동할 수 있습니다.

### 사용 치즈

월간 달력에서 날짜별 후원 내역을 확인하고, 사용량에 따라 달력의 색상을 구분합니다. 최근 14일 그래프와 전체·최근 사용량, 월 기준 일평균도 함께 볼 수 있습니다.

조회 결과는 표시 개수를 선택해 나누어 볼 수 있으며, 과거 내역 전체 동기화를 지원합니다.

### 카페 공지

카페 공지를 모아 확인하고 **선택 읽음** 또는 **일괄 읽음**으로 정리합니다. 기간을 지정해 저장된 과거 공지를 조회하거나 카페에서 다시 불러올 수 있습니다.

삭제가 확인된 공지는 앱 저장소에서도 영구 삭제되어 과거 공지 복구 대상에서 제거됩니다.

### 방송 기록

월간 달력에서 방송한 날짜를 선택하면 해당 방송 목록을 확인할 수 있습니다. 방송 시간 통계와 다시보기 링크를 제공하며, 방송 정보와 썸네일을 Mac에 보관합니다.

썸네일 가져오기·내보내기와 방송 시각 수동 수정도 지원합니다.

### 위젯과 알림

작은 크기와 중간 크기의 macOS 위젯으로 방송 상태, 채널 지표와 이용 기간을 확인합니다. 위젯을 클릭하면 앱의 기존 창을 앞으로 가져옵니다.

방송 시작·종료·제목 변경, 새 영상과 카페 공지, 기념일·결제일 등의 안내를 macOS 알림으로 받을 수 있습니다.

### 화면과 설정

창 크기에 맞춰 화면 배치와 탐색 메뉴가 바뀝니다. 작은 창에서는 하단 탐색 메뉴를 사용하고, 넓은 창에서는 달력과 기록을 함께 볼 수 있습니다.

배경 이미지를 직접 선택하고 창 투명도, 새로고침 간격과 링크를 여는 브라우저를 설정할 수 있습니다.

데이터 관리의 **모든 데이터 삭제**에서 최종 확인 후 앱 전용 기록·설정·로그인·썸네일·배경 이미지·캐시를 초기화하고 재실행할 수 있습니다.

## 처음 설치하기

1. [최신 릴리즈](https://github.com/xXkurotoriXx/jjogae-macOS/releases/latest)에서 **DMG 파일**을 다운로드합니다.
2. DMG를 열고 **쪼개 상황실.app**을 **응용 프로그램** 폴더로 옮깁니다.
3. 앱을 실행합니다. 실행이 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기 → 열기**를 선택합니다.
4. 앱 설정에서 치지직·네이버와 YouTube에 로그인합니다.
5. 상단의 **전체 새로고침**을 눌러 정보를 불러옵니다.

알림을 사용하려면 macOS의 알림 권한을 허용해 주세요.

## 업데이트하기

기존 사용자는 앱 메뉴 또는 설정에서 다음 순서로 업데이트할 수 있습니다.

**업데이트 확인 → 업데이트 설치 → 설치 및 재실행**

앱은 GitHub의 공개 배포 파일을 내려받고 전자서명을 확인한 뒤 새 버전으로 교체합니다. 저장된 기록과 설정은 유지됩니다.

**업데이트 자동 확인**을 켜면 앱이 실행되는 동안 주 1회 새 버전을 확인합니다. 설치는 업데이트 안내에서 직접 선택합니다.

## 동기화와 데이터 보관

- 자동 새로고침 간격은 **1분·5분·10분·1시간** 중 선택할 수 있습니다.
- 상단의 **전체 새로고침**으로 현재 정보를 즉시 다시 확인할 수 있습니다.
- 채널 정보와 계정 정보는 앱에서 치지직·네이버·YouTube에 직접 요청합니다.
- 기록·설정·배경 이미지·썸네일은 Mac의 앱 전용 저장소에 보관합니다.
- 위젯에 필요한 정보는 앱과 위젯의 공유 저장소에 보관합니다.
- JSON 가져오기·내보내기로 기록을 보관하거나 옮길 수 있습니다.

개인정보 처리와 데이터 관리에 관한 자세한 내용은 [개인정보처리방침](./PRIVACY.md)을 확인해 주세요.
